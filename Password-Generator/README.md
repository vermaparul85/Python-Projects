# Password Generator
* The objective is to take the inputs from the user and generate a random password.

* The program will ask:
  <br>How many letters would you like in your password?
  <br>How many symbols would you like?
  <br>How many numbers would you like?

* Password Generation has been demonstrated using different methods as stated below:
  * Method 1 - using for loop and random.choice function
  * Method 2 - using list comprehensions and random.choice function
  * Method 3 - using randon.choices function
  * Method 4 - using randon.sample function
